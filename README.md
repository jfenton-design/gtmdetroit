# GTMDetroit

Homepage for [GTMDetroit.com](https://gtmdetroit.com): a quarterly, in-person meetup for Detroit's go-to-market practitioners. No pitches, no vendors.

- `index.html` is the whole site (one static page, no build step).
- Registration runs through Luma: https://luma.com/tm0iu4oz
- Hosted on GitHub Pages; `CNAME` points it at gtmdetroit.com.
